Title: plotCorrelation --removeOutliers scales by median(|x|) instead of the median absolute deviation, so it removes (almost) nothing

- [x] Search whether this issue (or a similar issue) has been solved before: no prior report found (nearest: #9, the 2013 request for the option; #1406 asks how to get the matrix after outlier removal).
- [x] deepTools version: 3.5.6 (`master` @ `ea0f68bb`; also reproduced on 3.5.1 and 3.3.1); Python 3.12.3
- [x] Full command producing the issue: `plotCorrelation -in m.npz --corMethod pearson --whatToPlot heatmap --removeOutliers --outFileCorMatrix cor.tab` (the script below calls the function directly)
- [x] Output printed: see below

**What happens.** `Correlation.get_outlier_indices` (`deeptools/correlation.py`, lines 117-119):

```python
median = np.median(data)
b_value = 1.4826  # value set for a normal distribution
mad = b_value * np.median(np.abs(data))
```

The docstring cites Iglewicz & Hoaglin's MAD method and the `--removeOutliers` help says "median absolute deviation (MAD) method applying a threshold of 200". The MAD is `median(|x - median|)`; `median(|x|)` is, for non-negative counts, the median itself. A bin is therefore only flagged when `|x - median| > 200 * 1.4826 * median`, i.e. when it is about 300 times the typical count, and the option leaves the very bins it is meant to remove ("bins with abnormally high reads counts artificially increase pearson correlation") in place.

**Minimal reproduction** (5,000 Poisson(100) bins plus one bin of 5,000 — 50 times the median and 472 MADs away; shrinking showed a single planted bin is enough):

```python
import numpy as np
from deeptools.correlation import Correlation

data = np.random.RandomState(0).poisson(100.0, 5000).astype(float)
data[123] = 5000.0
med = np.median(data)
mad = np.median(np.abs(data - med))
print("median %.0f, MAD %.0f, planted bin is %.0f MADs from the median" % (med, mad, (5000 - med) / (1.4826 * mad)))
print("flagged by get_outlier_indices (threshold 200):", Correlation.get_outlier_indices(data))
assert 123 in Correlation.get_outlier_indices(data), "the outlier was not flagged"
```

Expected: `[123]`. Through the command line, on three samples of 5,000 Poisson(100) bins with 25 planted bins of ~4,000 in every sample, `plotCorrelation --removeOutliers` removes 0 bins and reports Pearson 0.998 between all pairs; with the documented rule the 25 bins are removed and the Pearson correlations are −0.002, 0.001 and 0.016 (the samples are independent noise).

**Fix.** `mad = b_value * np.median(np.abs(data - median))`; a patch with a test is ready and a PR follows. Note that `remove_outliers` only removes bins flagged in *every* sample (intersection), which the code comments but the help does not; the fix does not change that.
