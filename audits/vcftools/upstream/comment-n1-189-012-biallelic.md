`--012` writes biallelic sites only: `output_as_012_matrix` skips every site with more than one ALT allele (`if (e->get_N_alleles() > 2) continue;`) and prints `012: Only outputting biallelic loci.` once in the log, after the "kept N out of a possible N Sites" line, which counts the sites that passed the filters, not the ones written. The 351 missing sites in your file will be the multi-allelic ones (`vcftools --vcf sar.vcf --min-alleles 3 --kept-sites --out multi` lists them). To make the log count match the matrix, add `--min-alleles 2 --max-alleles 2` to the command. The man page's `--012` text does not mention the restriction (the `--IMPUTE` text does); a sentence there would save the next person this question.
