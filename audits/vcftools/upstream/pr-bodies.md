### PR 1 — `fix/tmpname-buffer-size` — "Size the temporary-file name buffers for the terminating NUL"

Fixes #NNN.

The temporary-file writers (`--012`, `--plink`, `--hap-r2`, `--geno-r2`, `--geno-chisq`, the
interchromosomal and SNP-list r² outputs, `--ldhat`, `--ldhat-geno`, `--ldhelmet`) build the `mkstemp`
template in a `std::string` and copy it with `strcpy` into a stack array of `new_tmp.size()` bytes, one
byte short of the terminating NUL. With the fortified string functions that current compilers enable by
default (`_FORTIFY_SOURCE=3` on Ubuntu 24.04, Fedora and Debian 13 with the default `-g -O2`), every
one of these modes aborts with `*** buffer overflow detected ***` before writing any output; without
fortification the NUL is written past the end of the array.

This sizes the arrays `new_tmp.size()+1` at all 19 sites (`variant_file_format_convert.cpp`,
`variant_file_output.cpp`). No other change. On the fortified build every mode above now runs; on a
non-fortified build the outputs are byte-identical to before (checked for `--012`, `--plink`,
`--hap-r2`, `--geno-r2` on a 40-individual VCF).

### PR 2 — `fix/relatedness2-missing-genotypes` — "relatedness2: count each individual's heterozygous sites over the sites called in both"

Fixes #NNN.

`output_indv_relatedness_Manichaikul` computes the KING-robust kinship estimate
`(N_AaAa − 2·N_AAaa) / (N_Aa(i) + N_Aa(j))` with `N_AaAa` and `N_AAaa` counted over the sites at which
both individuals are called but `N_Aa(i)` over every site at which i is called. In Manichaikul et al.
(2010) all four counts run over the same SNPs. With missing genotypes the extra heterozygous sites in
the denominator scale the estimate down by about the pairwise call rate: with 20 % of genotypes missing
at random a duplicate pair reports 0.40 instead of 0.50 and a parent–offspring pair 0.19 instead of
0.24 (numbers and generator in the issue).

This counts `N_Aa` per pair, over the sites at which the other individual is called (an N×N array in
place of the N vector, the same shape as `N_AaAa`), and prints the per-pair counts in `N1_Aa` / `N2_Aa`.
With no missing genotypes nothing changes; with the 20 % case above the output equals the estimator
computed independently over the shared sites (0.5000 / 0.5000 / 0.2373 / 0.2565).
