Title: `--relatedness2` underestimates kinship when genotypes are missing (the heterozygote counts in the denominator are not restricted to the sites called in both individuals)

`--relatedness2` implements the KING-robust estimator of Manichaikul et al. 2010,

    phi_ij = (N_AaAa - 2 N_AAaa) / (N_Aa^(i) + N_Aa^(j))

In `output_indv_relatedness_Manichaikul` (`variant_file_output.cpp`) `N_AaAa[i][j]` and `N_AAaa[i][j]` are counted over the sites at which both i and j are called, but `N_Aa[i]` is counted over every site at which i is called, whatever j's genotype:

```cpp
e->get_indv_GENOTYPE_ids(ui, geno_id);
if ((geno_id.first != geno_id.second) && (geno_id.first >= 0) && (geno_id.second >= 0))
{
    N_Aa[ui]++;
}
for (unsigned int uj=0; uj<meta_data.N_indv; uj++)
{
    ...
    e->get_indv_GENOTYPE_ids(uj, geno_id2);
    // N_AaAa and N_AAaa require both genotypes to be called
```

In the paper (and in KING) all four counts run over the same SNPs, those called in both individuals. With missing genotypes the denominator here includes heterozygous sites at which the partner is not called, and the estimate is scaled down by roughly the pairwise call rate. With no missing genotypes the two agree exactly.

**Reproduction.** 40 diploid individuals, 2000 biallelic sites, allele frequencies drawn uniformly on 0.05–0.5, containing two duplicate pairs (a00/b00, a01/b01), two parent–offspring pairs (a05/b05, a06/b05) and otherwise unrelated individuals; the same genotypes with 20 % of them set to `./.` at random. `vcftools --vcf x.vcf --relatedness2 --out x`, `RELATEDNESS_PHI`:

| pair | truth | complete genotypes | 20 % missing | KING-robust over the shared sites, 20 % missing |
|---|---|---|---|---|
| a00–b00 (duplicate) | 0.5 | 0.5000 | **0.4003** | 0.5000 |
| a01–b01 (duplicate) | 0.5 | 0.5000 | **0.4042** | 0.5000 |
| a05–b05 (parent–offspring) | 0.25 | 0.2372 | **0.1877** | 0.2373 |
| a06–b05 (parent–offspring) | 0.25 | 0.2527 | **0.2036** | 0.2565 |
| a00–a01 (unrelated) | 0 | −0.0045 | −0.0055 | −0.0070 |

Against the KING cut-offs users apply to this column (> 0.354 duplicate / MZ, 0.177–0.354 first degree, 0.0884–0.177 second degree) a duplicate pair at 20 % missingness reads as first degree and a parent–offspring pair sits at the first/second-degree boundary; at 30 % missingness it crosses. The option is normally run on the unfiltered call set, where 10–30 % missing genotypes are ordinary for RAD-seq and low-coverage data, precisely because its result decides which samples are kept.

The generator and the KING-robust recomputation are in `verify/v2_fst_ld_relatedness.py` and `verify/_synth.py` of the repository linked below; the numbers above are from `verify/v2_fst_ld_relatedness.out` (master at 1f87a83) and are the same on v0.1.16, v0.1.13 and Ubuntu's 0.1.16-3 package.

**Fix.** Count `N_Aa` per pair, as the sites at which i is heterozygous and j is called, and print those counts in `N1_Aa` / `N2_Aa`. A PR follows; with it the 20 % case gives 0.5000 / 0.5000 / 0.2373 / 0.2565 / −0.0070, equal to the recomputation, and complete-data output is unchanged to all printed digits.
