Title: (comment on #1142) intersect -split applies -F/-r to the summed block length of all hits; per-record fix + tests

_This is drafted as a comment on the existing open issue #1142
("bedtools intersect --split -r -f drops or wrongly accepts pairs when more than
one -b record overlaps the same -a record"), which already contains the
root-cause read of BlockMgr.cpp. Posting the confirmation on more releases and a
patch rather than a new issue._

Confirmed on master @ 614e9a5 and on the v2.31.1 and v2.30.0 release tags. A
minimal, non-BAM reproduction:

```bash
# A = chr1:100-200; three identical single-block reads, each 100% inside A
printf 'chr1\t100\t200\tgene\n' > a.bed
for r in r1 r2 r3; do printf 'chr1\t120\t170\t%s\t0\t+\t120\t170\t0\t1\t50\t0\n' $r; done > b.bed12

bedtools intersect -a a.bed -b b.bed12 -split -F 0.5 -wa -wb    # -> 0 lines
bedtools intersect -a a.bed -b b.bed12        -F 0.5 -wa -wb    # -> 3 lines
bedtools intersect -a a.bed -b b.bed12 -split -F 0.33 -wa -wb   # -> 3 lines
```

The break at `-F 0.333` is exactly 50 / (50+50+50): the denominator is the sum of
all three records' block lengths, as your analysis in #1142 describes
(`hitBlockSumLength` in `BlockMgr::findBlockedOverlaps`), and
`resultList.clearAll()` is all-or-nothing per query. Over 200 A intervals and
4000 random BED12 reads, `-split -F 0.5` gives **530 false negatives and 48 false
positives** against a per-record reference (838 true pairs); without `-split` the
per-record reference is matched exactly.

**Fix.** Compute and check `-F` (and the reciprocal test of `-r`) per database
record, using that record's own block length as the denominator, and drop only
the records that fail; keep `-f` as the cumulative fraction of the query covered
by the survivors, which is your intended #750 behaviour. Patch with tests
attached; the existing `intersect.t22.p` (`-F 0.20`) gains one line (the
two-block read now qualifies on `exon2` at 20/100), and new cases cover the three
identical reads and the #1142 isoform example. The full `make test` suite passes.
