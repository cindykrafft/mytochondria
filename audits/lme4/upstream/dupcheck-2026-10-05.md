# Duplicate check before filing — lme4 LM1 (2026-10-05)

Read-only check; nothing was posted, opened or pushed. Kit base: `master` @ `67d71b0` (2026-10-01; first prepared on `69588fa`). Fix branch: `fix/gamma-loglik-phi` @ `fd72146`. Our own comment on #867 and our PR #1000 are excluded as instructed.

**Finding:** with `disp_dof_correction = TRUE` (the default on master), `logLik()` of free-dispersion GLMMs is evaluated at `phi = deviance/n` (the family `aic()` plug-in). The fit and `sigma()` use `d_phi = deviance/(n - qEff)`.

**Verdict: FILE BUT MENTION #965.** No report of this mismatch exists. The upstream source is unchanged and the bug is still present. #965 is an open PR on the same class of inconsistency (sigma used by `aic()` vs the rest of the Laplace terms) and touches the same functions.
