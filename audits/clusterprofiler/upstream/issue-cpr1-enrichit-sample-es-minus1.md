### Describe your issue

Thanks for the quick fix to #3. One case on the `method = "sample"` path is still off: a gene set that sits entirely at the bottom of the ranked list (ES = -1) gets p ≈ 1/(number of negative permutations + 1), about 1e-05 with 2e5 permutations, however many permutations are run. The exact same-sign p for that set is about 0.001. `adaptive = TRUE` with `method = "sample"` does the same. `permute` and `multilevel` are fine, and so is the mirror case at the top of the list (ES = +1).

As far as I can tell, the cause is that on the `sample` path the observed ES comes from `calculate_es_details()` while the permutation scores come from `calculate_es_sparse()`. For this set the two don't produce bit-identical values, so no permutation ever counts as `<=` the observed ES. Comparing against the observed ES recomputed with `calculate_es_sparse()` (in `gsea()` and `gsea_adaptive()`, `sample` path only) brings the p-value back to the exact value, about 0.0011 here. The change is a few lines in each of the two functions in `src/gsea.cpp`. I'm happy to open a PR with it and a small test against the exact enumeration below if that helps.

### Reproducible example

```r
library(enrichit)
set.seed(1)
stats <- sort(setNames(rnorm(24), sprintf("g%02d", 1:24)), decreasing = TRUE)
es_of <- function(idx) { hit <- seq_along(stats) %in% idx; w <- abs(stats) * hit
  run <- cumsum(ifelse(hit, w / sum(w), -1 / (24 - length(idx)))); run[which.max(abs(run))] }
null <- apply(combn(24, 3), 2, es_of)                  # exact null: all 2,024 three-gene sets
p_exact <- mean(null[null < 0] <= -1)                  # same-sign p for ES = -1
run <- function(...) suppressWarnings(as.data.frame(gsea(stats, list(S = names(stats)[22:24]),
  minGSSize = 1, maxGSSize = 23, nPerm = 2e5, seed = 5, verbose = FALSE, ...)))$pvalue
signif(c(exact = p_exact, sample = run(method = "sample"),
         sample_adaptive = run(method = "sample", adaptive = TRUE),
         permute = run(method = "permute"), multilevel = run(method = "multilevel")), 3)
```

Output:

```
          exact          sample sample_adaptive         permute      multilevel 
       1.07e-03        1.08e-05        2.16e-05        9.42e-04        8.19e-04 
```

On four other random lists (seeds 2 to 5) `sample` gives 8.4e-06 to 1.8e-05 where the exact p is 0.0008 to 0.0018.
