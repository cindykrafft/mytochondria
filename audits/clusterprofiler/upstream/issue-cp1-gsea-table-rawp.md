### Prerequisites

- [x] latest release: clusterProfiler 4.20.0 (Bioconductor 3.23) with CRAN enrichit 0.2.1 (2026-08-04) reproduces it; `devel` 4.21.1.003 with enrichit `devel` 0.2.2 does not

### Describe your issue

**Expected:** as in clusterProfiler ≤ 4.18, `as.data.frame(gseGO(...))` contains the gene sets with
`p.adjust <= pvalueCutoff` (the NEWS for 4.21.1.003 and enrichit 0.2.2 restore exactly this).

**Got** with any clusterProfiler 4.19.3–4.21.1.002 and enrichit ≤ 0.2.1 — i.e. every current
release install, because enrichit 0.2.2 is not on CRAN yet: the table contains every set with raw
`pvalue <= pvalueCutoff` (`enrichit/R/gsea.R:354` in 0.2.1 filters on `pvalue` only). On GO BP with
18,870 ranked genes that is 717 rows of which 515 have p.adjust > 0.05 (max 0.44); a ranked list of
pure noise gives 292 "enriched" terms with none at p.adjust ≤ 0.05. Shrinking the example showed
that any collection reproduces it: 400 random sets on 5,000 noise genes give 14 rows, all with
p.adjust > 0.05 (max 0.965), under enrichit 0.2.1 and 0 rows under 0.2.2.

**Ask:** a CRAN release of enrichit 0.2.2 (or a `>= 0.2.2` requirement in the release branch's
DESCRIPTION), so that release users get the documented behaviour; until then a line in the book/
NEWS telling Bioconductor 3.23 users to filter `p.adjust` themselves.

Found in Mytochondria, a volunteer project that checks the numerical core of research software and verifies every finding by execution (methods and harnesses: https://github.com/cindykrafft/mytochondria/tree/main/audits/clusterprofiler)

### Reproducible example

```r
library(clusterProfiler)          # 4.20.0 (Bioc 3.23) or devel 4.21.1.002, with CRAN enrichit <= 0.2.1
set.seed(1)
geneList <- sort(setNames(rnorm(5000), paste0("g", 1:5000)), decreasing = TRUE)   # pure noise
term2gene <- unique(data.frame(term = rep(paste0("S", 1:400), each = 40), gene = sample(names(geneList), 16000, replace = TRUE)))
x <- suppressWarnings(GSEA(geneList, TERM2GENE = term2gene, pvalueCutoff = 0.05, verbose = FALSE, seed = 1))
res <- as.data.frame(x)
cat("enrichit", as.character(packageVersion("enrichit")), "rows:", nrow(res), " rows with p.adjust > 0.05:", sum(res$p.adjust > 0.05), " max p.adjust:", round(max(res$p.adjust), 3), "\n")
stopifnot(all(res$p.adjust <= 0.05))   # expected to pass
```

Output (enrichit 0.2.1):

```
enrichit 0.2.1 rows: 14  rows with p.adjust > 0.05: 14  max p.adjust: 0.965
Error: all(res$p.adjust <= 0.05) is not TRUE
```

Output (enrichit 0.2.2, GitHub `devel`): `rows: 0  rows with p.adjust > 0.05: 0`.
