Title: p7_Null2_ByTrace() (SSE/NEON/VMX) scores insert-state residues with match emission odds, and region_trace_ensemble() treats each sampled domain's first residue as outside the domain

<!-- EddyRivasLab/hmmer has no issue template. First filing (with PR against develop). Kept short on purpose: the a37e75b commit message called the AI-submitted #348 "verbose but correct". -->

**Version:** `develop` @ 37f7148; same code in 3.4, 3.3.2 and 3.1b2 (all built and run).

These two affect the null2 correction of domains in regions that go to stochastic traceback clustering (`clu` > 0 in `--tblout`).

**1. Inserts counted as matches.** In `impl_sse/null2.c` (`p7_Null2_ByTrace`, line 163; identical in `impl_neon/null2.c:162` and `impl_vmx/null2.c:172`):

```c
// s = ( (tr->st[z] == p7T_M) ?  p7X_M : p7X_I);  // We don't need the state type <s>, but this is how you'd get it.
q = p7X_NSCELLS * ( (tr->k[z] - 1) % Q) + p7X_M;
```

Every M or I residue goes into the match cell, so insert residues get the node's match emission odds. The I cells are summed afterwards with odds 1.0 (line 201), but they are never filled. `p7_GNull2_ByTrace()` counts inserts in IMX (`generic_null2.c:182`) with `exp(ISC)` = 1.0. `s` was unused from the start (d277c46), and 0529ea3 commented it out for `-Wall`.

**2. Off by one in `region_trace_ensemble()`** (`p7_domaindef.c:628`):

```c
for (; pos <= ddef->tr->sqfrom[d]; pos++) ddef->n2sc[ireg+pos-1] += 1.0;   /* "outside" */
for (; pos <= ddef->tr->sqto[d];   pos++) ddef->n2sc[ireg+pos-1] += null2[...];
```

`sqfrom[d]` is the domain's first M-emitted residue, so in every sample that residue gets 1.0 instead of its null2 ratio.

Across human Swiss-Prot (20,431 reviewed entries) with default options, 17 of 194 fn3 hits and 9 of 483 Pkinase hits change score by up to 0.9 bits, and E-values move by 0.74–2.0×. On synthetic 2–6-domain proteins where half of the domains carry a low-complexity insertion, scores move by up to 5.4 bits (fn3) and E-values by up to 50×. None of these runs changed which hits are reported or included at the default thresholds.

**Fix** (PR follows): count the residue in the I cell when `tr->st[z] != p7T_M` (three files), and use `pos < sqfrom[d]` in the first loop. The PR adds a `utest_null2_trace()` to the SSE null2 test driver, which compares against `p7_GNull2_ByTrace()` on emitted traces and fails without the first change. `make check` passes. I could only build and run the SSE implementation. The NEON and VMX edits are the same one-line change.
