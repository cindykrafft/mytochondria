Title: With `clusters` given as a factor, `scDblFinder.stats` reports 0 observed doublets for every combination and `scDblFinder.cluster` holds the integer codes

**Describe the bug**

In `scDblFinder()`:

```r
d$cluster <- NA
d[colnames(sce),"cluster"] <- clusters
```

Assigning a factor into a logical `NA` column stores its integer codes. The artificial doublets' origins are built from the level names ("A+B"), so `.getDoubletStats` names the expected combinations "1+2", "1+3", … while the called doublets' `mostLikelyOrigin` values are "A+B", …: `metadata(sce)$scDblFinder.stats` has `observed = 0` in every row, `FNR` and `difficulty` are `NA`, `plotDoubletMap` has nothing to show, and the `scDblFinder.cluster` column returned to the user holds 1, 2, 3 instead of the labels. The same labels passed as a character vector (or integer labels) work. A colData column of cell types is usually a factor, and so is `mockDoubletSCE()$cluster`.

**MRE -- Minimal example to reproduce the bug**

```r
library(scDblFinder); library(SingleCellExperiment)
set.seed(1)
sce <- mockDoubletSCE()                                        # sce$cluster is a factor
res <- scDblFinder(sce, clusters="cluster", verbose=FALSE)
metadata(res)$scDblFinder.stats[, c("combination","expected","observed","FNR")]
#   combination expected observed FNR
# 1         1+2    1.356        0  NA
table(res$scDblFinder.cluster)                                 # 1 and 2, not cluster1 / cluster2
res2 <- scDblFinder(sce, clusters=as.character(sce$cluster), verbose=FALSE)
sum(metadata(res2)$scDblFinder.stats$observed)                 # 26, the number of doublets called
```

**Traceback**

Not an R error.

**Session info**

Reproduced on scDblFinder 1.16.0 (Bioconductor 3.18, R 4.3.3) and on 1.8.0 and 1.12.0 built from their release commits; the two lines are the same on `devel` (2d0e5e4, `R/scDblFinder.R`). [submitter: paste `sessionInfo()`]

**Fix**

A PR follows: convert a factor to character before the assignment (`if(is.factor(clusters)) as.character(clusters) else clusters`). With it a factor gives the same stats table as the character labels and the label column; the package's tests pass.
